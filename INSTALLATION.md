# Установка и первый запуск Drone Warfare

## Важно про ошибку namespace/folder

Если tModLoader показывает ошибку вида:

```text
System.Exception: Пространство имён и название папки не совпадают.
Пространство имён верхнего уровня должно совпадать с названием папки.
```

значит tModLoader открыл не ту папку как корень мода.

В этом репозитории исходники tModLoader-мода лежат во вложенной папке:

```text
DroneWarfare/
```

Именно эта папка должна оказаться в `ModSources`, потому что верхнее пространство имён кода называется `DroneWarfare`.

Неправильно:

```text
ModSources/Drone-Warfare-codex-terraria/
```

Правильно:

```text
ModSources/DroneWarfare/
```

То есть если ты скачал репозиторий с GitHub как `.zip`, не клади в `ModSources` всю распакованную папку с названием репозитория. Открой её и скопируй внутрь `ModSources` именно вложенную папку `DroneWarfare`.

## Как установить из GitHub ZIP

1. Скачай репозиторий с GitHub через **Code → Download ZIP**.
2. Распакуй архив.
3. Внутри распакованной папки найди папку `DroneWarfare`.
4. Скопируй именно её в папку tModLoader `ModSources`.
5. В tModLoader открой **Workshop → Develop Mods**.
6. Выбери **Drone Warfare** и нажми **Build + Reload**.

## Где найти добавленный предмет

На текущем этапе добавлен один предмет:

- русское название: `FPV-контроллер`;
- английское название: `FPV Controller`;
- внутреннее имя класса: `FPVController`.

## Как получить предмет через крафт

`FPV-контроллер` крафтится на наковальне из одного из двух вариантов рецепта:

```text
10 Wire
2 Lens
5 Iron Bar
```

или:

```text
10 Wire
2 Lens
5 Lead Bar
```

## Как получить предмет через чит-моды

Если используешь Cheat Sheet, Hero's Mod или похожий мод, ищи предмет по одному из названий:

```text
FPV Controller
```

или:

```text
FPV-контроллер
```

Если поиск по локализованному названию не сработает, попробуй внутреннее имя:

```text
FPVController
```

## Что делает предмет сейчас

Пока это тестовый предмет фундамента v0.1.0 Alpha. При использовании он создаёт видимый временный FPV-дрон на базе ванильной текстуры. Дроном можно управлять через WASD, клавиша F включает/выключает управление, клавиша G подрывает текущую заготовку. Полноценной камеры, HUD, payload-урона и мультиплеерной синхронизации ещё нет — это следующие задачи разработки.
